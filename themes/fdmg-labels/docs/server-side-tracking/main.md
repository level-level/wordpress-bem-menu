# Server Side Tracking

This project uses server side tracking.
Server side tracking has been implemented using the [fdmg-server-side-tracking](https://github.com/level-level/fdmg-server-side-tracking) plugin.

Customizations have been made for this project, which is documented in the files below.

- [Tracking page data](./tracking-page-data.md)
- [Tracking user data](./tracking-user-data.md)
